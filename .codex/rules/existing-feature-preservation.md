# 既存機能の保護

このプロジェクトでは、すでに存在している機能・表示・導線を、明示的な依頼なしに削除してはいけない。

## ルール

- 既存の機能、UI セクション、空状態メッセージ、ナビゲーション、リンク、ボタン、データ取得処理を削除しない。
- 余白や見た目の問題を直す場合でも、既存機能を非表示にする方法で解決しない。
- 既存機能の変更が必要な場合は、機能を維持したままレイアウト、スタイル、条件分岐を調整する。
- どうしても削除または非表示が必要に見える場合は、実装前にユーザーへ確認する。
- ユーザーが「戻して」「基に戻して」と依頼した場合は、自分が行った削除・非表示・挙動変更だけを戻し、他の変更を勝手に巻き戻さない。
